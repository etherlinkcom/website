- **DeFi users / crypto traders** looking for a fast, low-cost L2 to bridge assets, swap tokens, and use DeFi apps. The hero CTA ("Bridge now") and featured banner ("Make money on Etherlink") target this group directly.

- **Institutional / infrastructure partners** assessing Etherlink's credibility via the partner logo carousel (MetaMask, Fireblocks, Safe, LayerZero, etc.) and security/governance messaging.

## Key Messaging Themes

1. **Speed and low cost** -- The hero tagline ("fast, fair, and nearly free L2"), the "Ultrafast transactions" card (sub-500ms confirmations), and the "(Nearly) free" card (fraction of a cent fees) make performance and affordability the primary value proposition.

2. **Decentralization and security** -- Emphasized repeatedly: "true decentralization," "decentralized governance," "non-custodial rollup," "robust security" (Tezos-enshrined L1 security), "open and permissionless," and "permissionless by design." This differentiates Etherlink from centralized L2 competitors.

3. **EVM compatibility / developer familiarity** -- Targeting builders with messaging about deploying "any EVM codebase," familiar tools (MetaMask, Hardhat, Foundry), and comprehensive integrations (Subsquid, Fireblocks, Thirdweb, The Graph).

4. **Tezos as the underlying technology** -- The "Built on Tezos" section and Smart Rollups card explicitly position Tezos as the security and governance backbone, lending institutional credibility.

5. **Future-proofing and governance** -- On-chain governance via Tezos is highlighted as enabling community-driven upgrades, positioning Etherlink as an evolving, upgradable network rather than a static one.

6. **DeFi as the primary use case** -- The featured banner ("Make money on Etherlink"), the hero copy ("Bridge assets, swap instantly"), and the Bridge CTA all orient the homepage around DeFi activity as the main entry point for users.

7. **Ecosystem breadth** -- The 33-partner logo carousel and "Explore ecosystem" card signal a mature, populated ecosystem rather than an empty chain.

## Notes and Observations

- The **FeaturedSection** uses a hardcoded array (not CMS-driven). Currently only 1 featured item exists ("Make money on Etherlink"), though the carousel supports multiple.
- The **"Tezos X" card** in the Evm section is commented out in `fixture.ts`, reducing that section to a single card.
- The **ExperienceSection** component lives in `app/components/pages/Home/` (the older directory) rather than `RevampHome/`, suggesting it predates the homepage revamp but was retained.
- The bottom developer section uses `id="developers"` as an anchor target for the "Start building" ghost button in the hero and the "Start building" card in the Featured section.
- Partner logos are static images with alt text as the only identifier (no display names rendered on screen). The alt text uses inconsistent casing (e.g., "blockscout" vs "Layer3", "secret-netwrok" with a typo).
- The page has no visible stats/metrics section despite `StatsSection.tsx` being referenced in the original file list -- that file does not exist in the codebase.
